# V15 Adaptive Player Engine

V15 gebruikt walk-forward pre-match modelling, gekalibreerde 1X2-ensembles, aparte O2.5/BTTS ensembles en speler-/lineupimpact. Volledige squads en individuele spelerprofielen worden via Sportmonks geladen waar het abonnement en de competitie dit toelaten. Ontbrekende spelersdata wordt niet verzonnen.
